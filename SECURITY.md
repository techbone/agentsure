# Security Policy

AgentSure is experimental financial software. The MVP is capped, unaudited, and not suitable for meaningful funds.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Until a dedicated security address is published, contact the repository owner privately and include:

- affected component and version or commit;
- reproduction steps or proof of concept;
- potential impact;
- any suggested mitigation.

Never include private keys, seed phrases, Circle sessions, API keys, or real user data in a report.
## Supported version

Only the latest commit on `main` is supported during the MVP phase.
